# Validate if the setup for your session has been properly done

Validate if the setup for your session has been properly done

## Usage

``` r
validateSetup(training = "base")
```

## Arguments

- training:

  Character which training to validate setup for.

## Value

Whether your environment is ready

## Examples

``` r
if (FALSE) { # \dontrun{
library(OmopTrainer)
validateSetup()
} # }
```
